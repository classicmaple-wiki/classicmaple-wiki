## How to read this wiki

<CardGrid>
	<Card title="Official" icon="approve-check">
		Taken from official patch notes or posts. The badge links to the source.
	</Card>
	<Card title="Confirmed in game" icon="seti:image">
		Seen in the live game by a player, with a screenshot.
	</Card>
	<Card title="Unverified" icon="warning">
		Reported but not yet confirmed. Treat it as a lead, not a fact.
	</Card>
	<Card title="What changed" icon="list-format">
		When a value moves between builds, the old one is kept. See [What changed](/changes/).
	</Card>
</CardGrid>

Most pages are marked unverified right now. That is on purpose. If you are playing, you can fix that in a few
minutes: see [How to contribute](/contributing/).
