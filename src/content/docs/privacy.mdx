---
title: Privacy
description: What Classic Maple Wiki collects about visitors. Very little.
---

import { repositoryUrl } from '../../../site.config.mjs';

- **No accounts, no ads, no analytics, no cookies.** The site is static pages.
- **Hosting logs.** The site is hosted on [Vercel](https://vercel.com/legal/privacy-policy). Like any web host, it records requests, including your IP address and browser, for a short time to run and protect the service. We do not use those logs to track you.
- **Fonts and pictures** are served from this site, not from third parties.
- **The correction form** is hosted by [Tally](https://tally.so/help/privacy-policy). It keeps what you type, any screenshot you add, and the page you came from. If you give a name or an email, we use the name only to credit you and the email only to ask about your correction. We never publish your email.
- **GitHub contributions** happen on <a href={repositoryUrl}>GitHub</a>, under GitHub's own privacy policy. What you post there is public.
- **Drop rates** we show contain no player names. We keep only the kill count and the date.

Questions? <a href={`${repositoryUrl}/issues/new`}>Open an issue</a>.
