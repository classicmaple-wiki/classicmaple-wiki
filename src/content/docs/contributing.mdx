This wiki is built by players. You do not need to know how to code.

## The one rule

Every fact needs a **source** and a **build**.

- **Source:** official patch notes, an official post, or your own in-game screenshot.
- **Build:** the game version you saw it in. See the build list on [What changed](/changes/).

Not sure about a number? Submit it and mark it `unverified`.

## Three ways to help

1. **Report it.** <a href={`${repositoryUrl}/issues/new/choose`}>Open an issue on GitHub</a>, pick a form, fill in the
   blanks, attach a screenshot.
2. **Edit in the browser.** Use the **Edit page** link at the bottom of any page.
3. **Work locally.** Clone the repository, run `npm install`, then `npm run dev`.

The full guide, with the data format and the review process, is in <a href={`${repositoryUrl}/blob/main/CONTRIBUTING.md`}>CONTRIBUTING.md</a>.
