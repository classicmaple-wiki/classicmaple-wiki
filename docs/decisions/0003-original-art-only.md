# 0003: Original art only, kept minimal

Date: 2026-10-13. Status: accepted.

## Context

The design direction is modern plus vintage, with the wiki as a library of places. The first idea was to set each page in a scene from the game. Game scenes, sprites, and music are Nexon's copyrighted work. Private servers use them without a license and survive only because Nexon has not acted against them. That is not a footing for a site that takes donations and carries an agency's name. The asset and policy inventory in `docs/research/assets.md` records what Nexon actually says.

## Decision

The wiki uses only art it owns. The identity is original: wordmark, palette, type, icon style, and a small set of simple pixel motifs drawn for the site. The art stays minimal and not art heavy. The library of places is carried by color, light, composition, and naming rather than by detailed illustration.

Nexon art is not downloaded, extracted, or copied from other sites. The one possible exception is the owner's own in-game screenshots, used small and attributed, and only where the inventory marks that use as tolerated and the owner decides to allow it.

## Consequences

- No copyright exposure from the design itself. The fan site disclaimer and the content license stay as they are.
- Pages load faster. A palette and a few small motifs weigh almost nothing compared with scene images.
- The design system must do more with less. Light, color per place, and typography have to create the mood that a painted scene would have.
- Original motifs take time to draw. The launch set is small and grows after launch.
- If the owner later wants richer scenes, they are commissioned as original work, which is a cost decision for the owner.
