# License basis for the MapleClassic Wiki import

Decided by the owner on 2026-10-14 (spec 0005).

- We rely on the license MapleClassic Wiki states in its footer and its API rights info: CC BY-NC-SA 4.0.
- Their About page names CC BY-SA 4.0 for editor prose. We import no prose, only facts from their Cargo tables.
- We did not ask the maintainers. The license does not require it, and the owner chose not to.
- The importer stops if the stated license changes.
- If the maintainers or Nexon object, run `npx tsx scripts/import-mapleclassic.ts --remove-all`, or `--remove-page` for one page, and open a pull request.

The whole site's content is CC BY-NC-SA 4.0 from this date. See decision 0008.
